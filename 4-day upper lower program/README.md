# Four-Day Upper/Lower Training Program

Чотириденна програма з paired sets для гіпертрофії, зростання або збереження сили та збереження м’язової маси під час дефіциту калорій.

## Формат paired sets

`Paired sets` або `alternating sets` — це дві вправи, які виконуються почергово з коротким відпочинком. Такий формат також часто називають суперсетом, хоча класичний суперсет зазвичай передбачає майже відсутній відпочинок між вправами.

Такий варіант кращий для сили. Приклад силового paired set:

1. Жим лежачи.
2. 60 секунд відпочинку.
3. Згинання рук.
4. 60–90 секунд відпочинку.
5. Знову жим лежачи.

Груди й трицепс фактично отримують близько трьох хвилин до наступного підходу жиму, але цей час не витрачається пасивно.

Книга підтримує суперсети як спосіб скоротити тренування без обов’язкової втрати гіпертрофічного ефекту. Водночас поєднання двох важких багатосуглобових вправ може знижувати обсяг і якість роботи. Тому важкий жим, присідання або RDL не перетворюються на жорстке кругове тренування.

## Позначення

- `A1/A2` — вправи виконуються почергово.
- Після `A1` відпочиваєш зазначений час, виконуєш `A2`, знову відпочиваєш і повертаєшся до `A1`.
- У розминкових підходах парні вправи не потрібні.
- Робочі підходи рахуються окремо для кожної вправи.
- `RIR 2` означає, що після завершення сету залишилося б приблизно два технічно чисті повторення.

## Тижневий обсяг

Приблизний прямий і значущий обсяг:

| М’язова група | Робочі підходи на тиждень |
|---|---:|
| Груди | 10 |
| Спина | 13 |
| Передні дельти | 3 прямі + жими |
| Середні дельти | 5 |
| Задні дельти | 5 |
| Біцепс | 5 прямих + тяги |
| Трицепс | 5 прямих + жими |
| Квадрицепс | 13 обов’язкових, до 15 з опціональним блоком |
| Задня поверхня стегна | 9 |
| Сідниці | 9–12 |
| Литки | 6 |
| Кор | 12 |

Це не максимальний обсяг. Для дефіциту й приблизно пів року системного стажу цього достатньо. Спочатку потрібно довести, що відновлення та прогрес можливі на цьому обсязі.
