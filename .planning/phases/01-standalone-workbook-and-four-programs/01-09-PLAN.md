<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI/runtime config → Google adapter | Test locator and credentials enter only at runtime |
| observed Google state → pure reconciler | External state may be stale, malformed or collaborator-modified |
| ChangePlan → Sheets batchUpdate | Allowlisted desired changes become external mutations |
| Google response/error → evidence/log | External payload may disclose identifiers or personal values |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-18 | Spoofing/Tampering | live target selection | critical | mitigate | explicit apply, disposable marker, non-production alias, untracked ID, exact identity/title preflight, and checkpoint confirmation |
| T-01-19 | Elevation/Disclosure | Google credentials | high | mitigate | official google-auth, minimum Sheets scope, exact target allowlist, no Drive permission API, no CLI secrets |
| T-01-20 | Tampering | request compiler | high | mitigate | typed allowlisted changes, explicit field masks, RAW strings, Git-only formula registry and compiler contract tests |
| T-01-21 | Tampering/Repudiation | collaborator drift | high | mitigate | managed pre-fingerprint, bounded batches, post-observe hash, bounded retry and explicit conflict |
| T-01-22 | Denial | unowned objects | medium | mitigate | preserve/report unowned state and limit removal to owner-marked obsolete objects |
| T-01-23 | Information Disclosure | logs/UAT evidence | high | mitigate | redact before formatting; allow only alias/version/hash/count/kind/code/pass-fail; regression-test forbidden fields |
</threat_model>
