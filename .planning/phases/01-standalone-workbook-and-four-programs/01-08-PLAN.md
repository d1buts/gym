<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local runtime/OAuth → Google adapter | Test locator and installed-app credentials enter only at runtime |
| ChangePlan → Sheets batchUpdate | Allowlisted desired changes become external mutations |
| Google response/error → CLI/log | External payload may disclose identifiers or personal values |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-21 | Spoofing/Tampering | target selection | critical | mitigate | explicit apply, disposable marker, alias, untracked locator, exact identity/title preflight, managed locale/timezone reconciliation, exact post-state verification, and later owner checkpoint |
| T-01-22 | Elevation/Disclosure | installed-app OAuth | high | mitigate | official google-auth flow, minimum Sheets scope, untracked token, pre-auth 0600 file/0700 directory enforcement with redacted codes, no Drive permission API or service-account default |
| T-01-23 | Tampering | request compiler | high | mitigate | typed allowlist, explicit field masks, RAW strings, Git-only formula registry and contract tests |
| T-01-24 | Information Disclosure | Google errors/CLI | high | mitigate | redact before formatting and allow only alias/version/hash/count/kind/code/status fields |
</threat_model>
