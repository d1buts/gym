## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| untrusted Sheet facts → formula cells | User text/numbers must not become executable formula templates |
| metric rows → dashboard aggregation | Incompatible cohorts or missing data could be misrepresented |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-13 | Tampering | formula injection | high | mitigate | formulas originate only from the Git registry; source text remains typed string/RAW and is never interpolated into formula text |
| T-01-14 | Tampering | metric eligibility | high | mitigate | canonical fixtures enforce working-set, validity, modality and cohort rules from METRICS.md |
| T-01-15 | Information Disclosure | dashboard | medium | mitigate | dashboard uses approved aggregate/status fields and excludes notes, health detail, credentials and locators |
| T-01-16 | Repudiation | formula drift | medium | mitigate | formula_version, registry ID, blueprint version and fixture regression travel together |
| T-01-17 | Denial | chart null/cohort behavior | low | accept | explicit helper ranges/status and live recalculation UAT detect Google rendering differences |
</threat_model>
